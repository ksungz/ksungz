# 김성재 | Frontend Engineer, Service UI

13년 동안 커머스, 게임, 플랫폼 서비스의 UI를 개발하고 운영했습니다.

11번가에서는 모바일웹 상품상세와 앱 WebView UI를 담당했습니다. 여러 상품 유형과
기기, 브라우저에 미치는 영향을 확인하며 변경 사항을 단계적으로 반영했고,
운영 문제가 발생하면 화면뿐 아니라 서버 상태와 배포 결과도 함께 확인했습니다.

React 기반 신규 UI 블록 약 18개를 구현하고, 공통 스타일을 제외한 운영 블록 SCSS
약 108개를 컴포넌트 구조에 맞춰 재구성해 React 저장소에 내재화했습니다.
기존 구조를 그대로 복제하기보다 변경과 검증이 가능한 화면 블록 단위로 정리했고,
결과는 실제 상품상세 첫 화면(ATF) 개선에 반영됐습니다.

## 주요 경험

- 모바일웹 상품상세와 앱 WebView UI 개발 및 운영
- React 기반 신규 UI 블록 약 18개 구현
- 운영 블록 SCSS 약 108개를 React 구조에 맞춰 재구성하고 내재화
- 약 2,384개 SCSS 파일의 Dart Sass 문법 전환과 산출물 검증
- 직렬 빌드를 병렬화해 대표 실행 시간을 약 24초에서 14초 내외로 단축
- 약 3년간 팀장으로 일정, 품질, 업무 분배와 고객사 커뮤니케이션 담당

## 작업할 때 지키는 기준

- 구현 전에 영향을 받는 화면, 환경과 협업 대상을 먼저 확인합니다.
- 큰 변경은 검증 가능한 단위로 나누고 실제 산출물과 운영 결과를 확인합니다.
- 직접 구현한 범위와 팀 작업에 참여한 범위를 구분합니다.
- 측정하지 않은 개선 효과는 수치로 표현하지 않습니다.
- AI가 만든 결과는 코드, 테스트, 빌드와 실행 결과로 다시 확인합니다.
