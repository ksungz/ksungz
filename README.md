# 김성재 | Frontend Engineer, Service UI

커머스, 게임, 플랫폼 서비스에서 UI를 개발하고 운영해 왔습니다.
11번가에서는 모바일웹 상품상세와 앱 WebView UI를 담당하며
다양한 상품 유형과 기기 환경에 맞춰 화면을 개선했습니다.

오래 운영된 화면을 바꿀 때는 기존 구조와 다른 화면에 미칠 영향을 먼저 살폈습니다.
기획, 디자인, 백엔드 담당자와 구현할 내용과 검증할 항목을 조율하고
변경한 뒤에는 실제 화면과 배포 결과를 점검했습니다.
AI 도구도 반복 작업에 활용하되 결과를 직접 검토해 적용했습니다.

하이브랩에서는 UI 개발과 함께 약 3년간 팀장 역할을 맡았습니다.
고객사의 요구사항을 조율하고 공수 산정, 업무 배분, 일정과 품질을 관리했습니다.

## 주요 경험

- 모바일웹 상품상세와 앱 WebView UI 개발 및 운영
- 운영 SCSS를 React 저장소로 이관하고 신규 UI 블록 약 18개의 스타일 연결
- 기존 운영 블록 SCSS 약 108개를 기준으로 스타일 구조 검토. 공통 SCSS는 이 숫자에서 제외
- AI를 활용한 약 2,384개 SCSS 파일의 Dart Sass 문법 전환과 산출물 검증
- 직렬 빌드를 병렬화해 대표 실행 시간을 약 24초에서 14초 내외로 단축
- 약 3년간 팀장으로 일정, 품질, 업무 분배와 고객사 커뮤니케이션 담당

## 작업할 때 확인하는 것

오래 운영된 화면을 바꿀 때는 기존 구조와 영향을 받는 화면을 먼저 확인합니다.
Sass 전환에서도 문법을 바꾼 뒤 CSS 산출물과 빌드 결과를 비교했습니다.
운영 문제가 발생했을 때는 서버 접근 권한을 받아 상태를 확인하고 배포 검증 환경도
함께 점검했습니다. 코드 변경에서 끝내지 않고 적용한 결과까지 확인하려고 합니다.
