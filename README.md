# 김성재 | AX Engineer

13년간 커머스·게임·플랫폼 서비스의 UI를 개발하고 운영했습니다.

현재는 현장에서 반복되는 업무, 문서와 작업 맥락의 단절, 검증 비용을 줄이기 위해
AI Agent, RAG, MCP와 자동화 워크플로를 직접 만들고 운영하고 있습니다.

AI가 사람의 판단을 대신하게 하기보다 필요한 맥락과 초안, 확인 항목을 준비하게 하고,
제품과 사용자에게 영향을 주는 결정은 사람이 맡는 방식을 선호합니다.

## 지금 집중하는 일

- 여러 AI 도구가 같은 문맥과 결정 기록을 사용할 수 있는 작업 환경
- 반복 업무를 자동화하되 사람이 최종 판단하는 Human-in-the-loop 구조
- AI 도입 전 위험과 미확인 범위를 먼저 드러내는 점검 도구
- 실제 운영 문제에서 시작해 배포와 개선까지 이어지는 AI 제품

## 경험의 기반

- 11번가 모바일웹 상품상세와 신규 서비스 UI 개발·운영
- 2,384개 SCSS 파일의 Dart Sass 전환과 결과 검증

- 약 3년간 팀장으로 일정, 품질, 업무 분배와 고객 커뮤니케이션 담당
