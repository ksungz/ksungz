# 김성재 | 서비스 개발과 운영

커머스, 게임, 플랫폼 서비스에서 UI를 개발하고 운영해온 김성재입니다. 11번가에서는 모바일웹 상품상세와 앱 WebView를 담당하며 여러 상품 유형과 이용 환경에 맞춰 화면을 개선했습니다. 변경 사항을 반영할 때는 기존 기능에 미치는 영향을 살피고 기획, 디자인, 개발 담당자와 작업 범위를 조율했습니다.

하이브랩에서는 약 3년간 팀장으로 고객사 요구사항과 팀의 작업 여건을 고려해 일정을 조율하고 업무 배분과 UI 결과물의 품질 관리를 맡았습니다.

최근에는 공동 프로젝트에서 상담 신청 홈페이지와 접수 내역을 관리하는 시스템을 만들고 있습니다. 필요한 기능을 정리하고 AI 개발 도구를 활용해 구현한 뒤 동작을 확인하고 배포하고 있습니다. 지난 논의와 남은 업무를 확인하는 협업 도구와 반복적인 자료 처리를 줄이는 도구도 만들어 활용하고 있습니다.

## 주요 경험

- 모바일웹 상품상세와 앱 WebView UI 개발 및 운영
- 운영 SCSS를 React 저장소로 이관하고 신규 UI 블록 약 18개의 스타일 연결
- 기존 운영 블록 SCSS 약 108개를 기준으로 스타일 구조 검토. 공통 SCSS는 이 숫자에서 제외
- AI를 활용한 약 2,384개 SCSS 파일의 Dart Sass 문법 전환과 산출물 검증
- 직렬 빌드를 병렬화해 대표 실행 시간을 약 24초에서 14초 내외로 단축
- 약 3년간 팀장으로 일정, 품질, 업무 분배와 고객사 커뮤니케이션 담당

함께 점검했습니다. 코드를 수정한 뒤에는 적용된 화면과 배포 결과도 확인했습니다.
