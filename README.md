# 김성재 | Frontend Engineer · Service UI

13년 동안 커머스·게임·플랫폼 서비스의 UI를 개발하고 운영했습니다.

현재는 11번가 모바일웹 상품상세와 신규 서비스 화면을 맡아, 기기와 브라우저별 차이를
확인하고 운영 중 발생하는 문제에 대응하고 있습니다.

공통 UI와 SCSS 구조를 정리했으며, AI 보조 도구를 활용한 2,384개 SCSS 파일의
Dart Sass 전환과 React·TypeScript 컴포넌트 이관에도 참여했습니다. 오래된 구조는
서비스에 미치는 영향을 살피며 단계적으로 개선합니다.

최근에는 AI 도구를 코드 검토, 문서 초안과 반복 작업에 활용하고 결과는 직접 실행해
확인합니다. 개인 프로젝트에는 해결하려는 문제, 구현 범위, 확인한 결과와 남은 한계를
함께 기록합니다.
